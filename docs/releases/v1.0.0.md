# OpsPilot v1.0.0 — Portfolio Release Notes (Prepared)

Status: release notes prepared; no tag or GitHub Release has been created.

## Highlights

- Evidence-grounded incident lifecycle from synthetic fault through independent verification.
- Deterministic policy, durable human approval, checkpoint resume, audit, and OTel correlation.
- Historical incident memory with offline Dense/Sparse/Hybrid RRF evaluation.
- MCP typed interoperability that cannot authorize or directly execute.
- Governed Ansible/Harness execution with Transactional Outbox, UNKNOWN, and reconciliation.
- Synthetic legacy Ansible-over-SSH compatibility with fixed script/systemd mapping.
- Reproducible Portfolio benchmark, safety/reliability matrices, and three-run demo evidence.

## Architecture

The v1 freeze is Alert/Fault → Incident → Evidence → Historical Memory → Investigator → Structured
Action → deterministic Policy → HITL → durable Resume → governed Execution → Ansible/Harness →
Verification → Audit/Telemetry. M9+ does not alter this prepared release.

## Demo and evaluation

`make demo-local` runs the canonical synthetic lifecycle. `make portfolio-benchmark` regenerates
machine/human artifacts without OpenAI, Harness SaaS, remote MCP, or company network dependencies.
`make portfolio-check` applies code, test, security, benchmark, demo-artifact, and docs gates.

## Security

Strict actions, target/profile allowlists, fixed execution mappings, evidence ownership, durable HITL,
no arbitrary shell/tool, fail-closed UNKNOWN dispatch, and secret-safe output are covered by the v1
safety matrix. These controls are not a certification.

## Known limitations

This is a synthetic personal portfolio project, not production-deployed. Real LLM and Harness SaaS
evaluation are optional and must say `NOT RUN` when absent. See
[limitations](../evaluation/limitations.md).
